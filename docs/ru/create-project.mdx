# Создание проекта

Проекты — основной способ организовать документы в системе. В каждом проекте
хранятся документы, снимки и история проверок. Интерфейс интуитивно понятен:
в большинстве случаев достаточно нескольких кликов, чтобы начать работу.

## Перед началом

Убедитесь, что у вас есть права на создание проектов. Если доступ закрыт,
обратитесь к администратору.

Документы принимаются в форматах PDF, DOCX и TXT. Система понимает кодировку
файла автоматически — вам не нужно указывать её вручную.

## Шаг 1. Откройте раздел «Проекты»

Нажмите **Проекты** в левой панели навигации. Вы попадёте на страницу со
списком всех доступных проектов.

Если список пустой, значит проекты ещё не созданы или у вас нет доступа
к существующим.

## Шаг 2. Создайте новый проект

Нажмите кнопку **Новый проект** в правом верхнем углу. Откроется форма
создания.

Заполните поля:

- **Название** — краткое название проекта. Вы должны использовать понятное
  имя, чтобы другие участники команды могли легко найти проект.
- **Описание** — необязательное поле. Укажите цель проекта или тип документов.
- **Команда** — выберите участников, которым нужен доступ.

Нажмите **Создать**. Система обработает запрос, и в большинстве случаев
проект появится в списке через несколько секунд.

## Шаг 3. Загрузите документ

После создания проекта вы попадёте на его страницу. Необходимо нажать кнопку
**Загрузить документ** и выбрать файл на вашем компьютере.

Гибкие настройки загрузки позволяют задать параметры проверки заранее:
язык документа, набор критериев и уведомления.

:::note
Максимальный размер файла — 20 МБ. Запрещено загружать файлы в формате EXE,
ZIP или других исполняемых форматов.
:::

После загрузки документ будет автоматически поставлен в очередь на проверку.
На данный момент система поддерживает одновременную обработку до 10 документов.

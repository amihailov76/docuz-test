# Как выбрать конфигурацию MaxPatrol SIEM

В зависимости от сложности IT-инфраструктуры организации вы можете применять следующие конфигурации MaxPatrol SIEM:

- **Для малонагруженных систем.** Рекомендуется для организаций, которые планируют выполнять периодическое сканирование узлов не чаще одного раза в месяц, получать поток событий не более 5000 событий в секунду и не планируют расширение IT-инфраструктуры.
- **Для средненагруженных систем.** Рекомендуется для организаций, которые планируют получать поток событий не более 15 000 событий в секунду и планируют расширение IT-инфраструктуры.
- **Для высоконагруженных систем.** Рекомендуется для организаций, которые планируют получать поток событий не более 50 000 событий в секунду на один конвейер.

Как правило, для территориально распределенных организаций подходит развертывание на нескольких площадках. MaxPatrol SIEM состоит из нескольких программных компонентов — это позволяет внедрить и масштабировать систему в организациях любого размера. В большинстве случаев достаточно стандартной конфигурации, однако при росте инфраструктуры вы должны добавить дополнительные конвейеры.

## Развертывание MaxPatrol SIEM на нескольких площадках

В крупных организациях вы можете развернуть в каждом подразделении одну из конфигураций MaxPatrol SIEM — локальную площадку. Каждая площадка имеет свой управляющий сервер — компонент MP 10 Core — и свою базу активов и инцидентов. Система обеспечивает эффективную синхронизацию учетных записей между площадками. С помощью компонентов PT MC площадки связываются между собой, в результате чего становятся доступными распределенный поиск событий и их репликация между площадками.

## Установка дополнительных конвейеров обработки событий

Конвейер обработки событий в общем случае состоит из компонентов MP SIEM Server и MP SIEM Events Storage и нескольких коллекторов. По умолчанию MaxPatrol SIEM содержит только один конвейер. Необходимо понимать, что количество дополнительных конвейеров ограничено лицензией.

Конвейер можно установить в каждом территориально удаленном филиале организации для сбора, обработки и хранения событий, произошедших на активах этого филиала. MP 10 Core осуществляет анализ событий со всех конвейеров и управляет задачами сканирования из центрального офиса.

Развертывание системы на нескольких конвейерах позволяет распределить нагрузку между ними и одновременно использовать единый сервер для хранения сведений обо всех активах и инцидентах, управления задачами сканирования IT-инфраструктуры и сбора событий, а также для просмотра и анализа событий.

## Пример параметров конфигурации

После выбора конфигурации укажите параметры в файле настроек:

```yaml
# Seperate settings for each pipeline
mp_siem:
  pipeline_count: 3
  max_events_per_second: 50000
```
